# Обзор репозитория

Этот репозиторий создан для практической работы по GitHub.

## Основные действия

- хранить учебные материалы в репозитории;
- создавать ветки для отдельных тем;
- фиксировать изменения коммитами;
- клонировать репозиторий для работы на компьютере.

Снимок `clone-screenshot.png` подтверждает наличие локальной копии.
